ADVANCED JAVA LAB PORTFOLIO - 13 WEEKS

Open index.html in Chrome, Edge or Firefox. No server is required for the portfolio pages.
Select a week, then open the Code / Commands tab to view every included source file and command. Use Copy code on each block.

The student portrait is kept in its original full-image proportions (no face cropping).

For Spring Boot weeks, configure your own local MySQL username/password in application.properties before running the sample project.
